AI Workflow

How I build with AI

Cronos AD and Tonnetz were built with Claude writing most of the code. That only works with a process around it, so this is mine.

01

Specify

I brief Claude with the client's own words plus my requirements, and get UI mockups before any feature is built.

02

Decide

Architecture and direction are my calls, such as moving Cronos AD from Windows Forms to Avalonia.

03

Reject

Output that misses the design goes back: overlapping UI, a scrolling main screen. Some rules become automated tests so they can't regress.

04

Verify

I test every build on real data, run the unit tests, and publish to the client, who tests again before use.
